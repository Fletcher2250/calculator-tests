
# Calculator Tests

## О проекте
Небольшой проект по автоматизированному тестированию
калькулятора на Python.

## Цель проекта
Практика написания автоматических тестов
с использованием Pytest.

## Функциональность
- Сложение чисел
- Вычитание чисел
- Умножение чисел
- Деление чисел
- Обработка деления на ноль

## Используемые технологии
- Python
- Pytest

## Установка
Установить Pytest:

```bash
pip install pytest
```

## Запуск тестов
Выполнить команду:

```bash
pytest -v
```

## Результат
7 автоматических тестов успешно пройдены.
